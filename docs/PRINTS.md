# Prints do Programa Funcionando

Este arquivo serve como guia para adicionar prints ao README.

## Prints recomendados

Inclua imagens das seguintes telas:

1. Tela inicial/calendario.
2. Tela de login/cadastro.
3. Pagina de grupos.
4. Pagina de estadios no desktop.
5. Pagina de estadios no celular/PWA.
6. Pagina de favoritos.
7. Pagina de perfil com avatar.
8. Pagina de noticias.
9. Aplicacao instalada no celular como PWA.
10. Aplicacao desktop aberta com Electron, se for demonstrar.

## Pasta sugerida

Crie uma pasta:

```txt
docs/prints/
```

E salve os arquivos com nomes simples:

```txt
docs/prints/01-calendario.png
docs/prints/02-login.png
docs/prints/03-grupos.png
docs/prints/04-estadios.png
docs/prints/05-favoritos.png
docs/prints/06-perfil.png
docs/prints/07-noticias.png
docs/prints/08-pwa-mobile.png
```

Depois, no README, use:

```md
![Calendario](docs/prints/01-calendario.png)
```
