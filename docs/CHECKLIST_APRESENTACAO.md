# Checklist para Apresentação

## Roteiro rápido de demonstração

1. Abrir a página inicial e mostrar o calendário.
2. Explicar os filtros por seleção e fase.
3. Fazer login ou mostrar usuário já logado.
4. Mostrar o vídeo de abertura.
5. Favoritar um jogo.
6. Ir para grupos e acompanhar uma seleção.
7. Voltar ao calendário e mostrar os jogos automáticos com estrela.
8. Abrir favoritos e mostrar jogos, seleções e estádios.
9. Abrir mapa dos estádios.
10. Filtrar por Canadá, EUA e México.
11. Favoritar um estádio.
12. Abrir perfil e mostrar dados/avatar.
13. Abrir notícias.
14. Explicar Supabase Auth, Database e Storage.
15. Explicar PWA/mobile e Electron/desktop como expansão.

## Pontos fortes para falar

- Projeto usa autenticação real.
- Dados do usuário ficam salvos no banco.
- Avatar é enviado para storage.
- O sistema tem personalização por usuário.
- O mapa é interativo.
- A página de notícias usa API e fallback.
- O projeto possui documentação, DER e guia de deploy.

## Pontos para assumir como evolução

- Melhorar responsividade em telas muito pequenas.
- Criar API REST própria em Node.js caso seja exigido.
- Gerar instalador desktop final.
- Publicar versão final em produção.
